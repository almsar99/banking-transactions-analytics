# Banking Transactions Analytics

Backend-приложение для анализа банковских транзакций из Excel-файла с генерацией JSON-ответов и аналитических отчётов.

### Проект демонстрирует:

- работу с pandas
- интеграцию с внешним API
- строгую типизацию (mypy strict)
- архитектурное разделение ответственности
- 100% покрытие тестами

---

## Возможности

### Веб-страница «Главная»

- Приветствие в зависимости от времени суток
- Сводка по картам:
  - последние 4 цифры
  - сумма расходов
  - кешбэк (1% от трат)
- Топ-5 транзакций
- Курсы валют (через API)
- Стоимость акций S&P 500 (через API)
- Метаданные генерации ответа

### Сервисы
- Выгодные категории повышенного кешбэка
- Инвесткопилка (округление трат)
- Простой поиск
- Поиск по телефонам (regex)
- Поиск переводов физлицам

### Отчёты
- Траты по категории
- Траты по дням недели
- Траты в рабочий/выходной день
- Декоратор автоматической записи отчёта в файл

## Разделение ответственности

### Проект разделяет:

- бизнес-логику
- загрузку данных
- работу с API
- слой представления (views)

Это позволяет легко менять источник данных или способ отображения без изменения основной логики.

## Установка

```bash
poetry install
```
## Настройка API

Проект использует Financial Modeling Prep API.

Создайте файл .env:

```env
FMP_API_KEY=your_api_key_here
```

Файл .env не хранится в репозитории.
В проекте присутствует .env_template с перечнем необходимых переменных.

## Запуск

```bash
poetry run python src/banking_transactions_analytics/main.py
```
Или с указанием даты:

```bash
poetry run python src/banking_transactions_analytics/main.py --date "2023-05-20 12:00:00"
```
